Личный сайт на Astro framework: https://ram1337.dev


При `npm run build` интеграция `integrations/asset-versions.mjs` добавляет `?v=<SHA-256 содержимого>` к локальным ресурсам в готовом HTML: CSS, скриптам, изображениям, иконкам и srcset. При изменении ресурса меняется его URL; неизменённые файлы сохраняют прежнюю версию. Хешированные имена модулей Astro/Vite продолжают обновлять вложенные импорты. Ссылки на API, подписки, внешние сервисы и страницы не изменяются. Настройки HTML-кеша на хостинге должны позволять проверку свежести страниц (ETag/Last-Modified или Cache-Control: no-cache).

В админке индивидуальный лимит подписки меняется в карточке пользователя → «Личная VPN-подписка» → «Разрешённое количество устройств». До выпуска подписки поле тоже доступно. ЛК получает badge из API, без фиксированного значения.
